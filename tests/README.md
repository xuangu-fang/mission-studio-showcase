# Test Strategy

Planned suites:

- public schema and fixture validation;
- event ordering, duplication, gaps, seek, and reset;
- projection consistency across views;
- fixed/adaptive clock and scale alignment;
- keyboard and reduced-motion behavior;
- Story Mode cancellation and Operator Mode inspection;
- unsupported-version and asset-failure states;
- Playwright interaction and screenshot regression;
- GitHub Pages subpath smoke test;
- prohibited secret/private-reference scan.
