# Payload context imagery

These locally optimized WebP images provide realistic visual context for the public POC. They are not observations from the synthetic Runtime Trace and must not be interpreted as geographically or temporally matched mission evidence.

| File | Source and credit | Use |
| --- | --- | --- |

| `camp-fire.webp` | [NASA Applied Sciences — Fires](https://appliedsciences.nasa.gov/what-we-do/disasters/fires), NASA Earth Observatory | wildfire context |
| `sentinel1-ships.webp` | [ESA Sentinel-1 English Channel](https://www.esa.int/ESA_Multimedia/Images/2019/04/English_Channel), contains modified Copernicus Sentinel data (2016–18), processed by ESA; CC BY-SA 3.0 IGO | maritime SAR context |
