# Decision Record

## S-001 — Public Showcase is independent of private source

- Status: Accepted
- The repository consumes only reviewed public contracts, fixtures, assets, and future API responses.

## S-002 — Static-first, live-later

- Status: Accepted
- The complete first experience runs from local fixtures on GitHub Pages. Live mode must not become a dependency of the public story.

## S-003 — React/TypeScript/Vite with Cesium adapter

- Status: Proposed default
- Confirm exact package versions in the bootstrap PR. Change only with measured benefit and a short decision note.

## S-004 — One event source drives every view

- Status: Accepted
- Mission truth is ordered public events; globe, graph, panels, charts, and story choreography are projections.

## S-005 — Open MCT is a reference/adapter, not the shell

- Status: Accepted
- Its telemetry concepts may inform later engineering views, but the Showcase owns the evidence-belief-action product narrative.

## S-006 — GitHub Pages is a showcase, not SaaS hosting

- Status: Accepted
- It serves static assets. Agent, Python, simulation, secrets, and sensitive data remain off Pages.

## S-007 — License pending owner review

- Status: Open
- Do not accept external code contributions or label the project open source until a license is selected.
