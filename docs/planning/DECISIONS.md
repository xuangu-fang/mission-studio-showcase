# Decision Record

## S-001 — Public Showcase is independent of private source

- Status: Accepted
- The repository consumes only reviewed public contracts, fixtures, assets, and future API responses.

## S-002 — Static-first, live-later

- Status: Accepted
- The complete first experience runs from local fixtures on GitHub Pages. Live mode must not become a dependency of the public story.

## S-003 — React/TypeScript/Vite with Cesium adapter

- Status: Accepted for the Gate A vertical slice
- Node 22.23.2, pnpm 11.24.0, React 19.2.8, TypeScript 7.0.2, Vite 8.2.2, and Cesium 1.144.0 are pinned in the initial implementation. Change only with measured benefit and a short decision note.

## S-004 — One event source drives every view

- Status: Accepted
- Mission truth is ordered public events; globe, graph, panels, charts, and story choreography are projections.

## S-005 — Open MCT is a reference/adapter, not the shell

- Status: Accepted
- Its telemetry concepts may inform later engineering views, but the Showcase owns the evidence-belief-action product narrative.

## S-006 — GitHub Pages is a showcase, not SaaS hosting

- Status: Accepted
- It serves static assets. Agent, Python, simulation, secrets, and sensitive data remain off Pages.

## S-007 — License pending owner review

- Status: Open
- Do not accept external code contributions or label the project open source until a license is selected.

## S-008 — Public contract is mirrored as reviewed release artifacts

- Status: Accepted
- The Showcase stores the reviewed `0.1.0` JSON Schemas and sanitized fixture generated by the private Core. Runtime and fixture tests validate the mirrored artifacts; the repositories never import source from one another.

## S-009 — The first world view has no remote availability dependency

- Status: Accepted for Gate A
- Cesium renders a local ellipsoid, AOI, and mission markers without a token or remote basemap. Public imagery can be added later with attribution and graceful fallback.

## S-010 — Story Mode and Operator Mode use different information density

- Status: Accepted for Gate A
- Story Mode projects the canonical trace into five semantic mission stages, one current causal explanation, a dominant world view, and simplified playback controls. Operator Mode retains the full mission graph, evidence, resources, event-level timeline, provenance, and counterfactual inspection surfaces. Both modes use the same validated events and projection clock; narrative text is a deterministic read model rather than a second story data source.

## S-011 — Multi-case visualization shares contracts, not hard-coded timelines

- Status: Accepted for Gate A+B
- Adaptive HSI、Wildfire Response 与 Maritime SAR 使用相同的 Public Manifest/Event/Outcome `0.1.0` validator 和 projection pipeline。Story stage anchor 从每条 trace 的 observation、belief、constraint 与 outcome event 派生；场景 catalog 只提供中文叙事与视觉编码，不拥有 mission truth。

## S-012 — Natural-language authoring is an optional private-Core connection

- Status: Accepted for Gate B preview
- Static Showcase 不包含模型 secret，也不向公共部署提供通用模型 proxy。开发者显式启动仅绑定 localhost 的 private Core 后，Showcase 可以提交自然语言 intent，并显示 DeepSeek 生成且通过 MissionIR validation 的 `proposal_only` 结果；浏览器不能将该结果标为已授权或直接执行。
